# MCP tools

The docs site runs an [MCP](https://modelcontextprotocol.io) server, so an AI agent (Claude Code, Codex, Cursor, VS Code Copilot, …) can look things up while it works: it searches these docs, reads live GitHub data for the `blue-core-lod` org, reads the Blue Core API spec, and reads and writes your notes. These pages cover every tool, what it's for, and how agents chain them.
