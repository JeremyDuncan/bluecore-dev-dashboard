# Welcome

This site collects the Blue Core developer documentation in one place.

## Start here: Bluecore Stack

**[Bluecore Stack](/blue-core-repos/bluecore-stack/)** is the core developer documentation. It covers setting up your environment, running the whole Blue Core stack locally with Docker Compose, and testing:

- [Local Development](/blue-core-repos/bluecore-stack/docs/local-development): run and change the stack on your machine
- [Configuration](/blue-core-repos/bluecore-stack/docs/configuration): environment variables and settings
- [Integration Testing](/blue-core-repos/bluecore-stack/docs/integration-testing) and [UI Testing](/blue-core-repos/bluecore-stack/docs/ui-testing): how the tests run
- [Architecture](/blue-core-repos/bluecore-stack/docs/architecture): how the services fit together

It's always one click away: **Bluecore Stack** in the top bar, and **Bluecore Stack: start here** in the sidebar.
